# 诗词拾光 · Task 1 + Task 2 + Task 3

面向小学生的古诗词启蒙网页，收录《义务教育语文课程标准（2022 年版）》附录 1 中 1～6 年级的 75 篇诗歌。采用米白、草木绿和暖黄色，搭配大字原文、逐字拼音、儿童白话释义。桌面与手机均可使用。

正式公开网址：[https://8aozi.github.io/poetry-time/](https://8aozi.github.io/poetry-time/)。项目进度已推进到 Task 4，但朗读方案经人工试听后舍弃，未集成到此目录；见 [Task 4 日志](../CHANGELOG.md) 和 [独立 Demo](../demos/task4-narration/README.md)。

## 立即使用

**最简单：直接双击本目录的 `index.html`。** 不需要安装依赖，也不需要联网。请保留整个目录，尤其是 `index.html`、`styles.css`、`app.js`、`learning-store.js`、`practice.js`、`practice-ui.js`、`assets/` 和 `data/poems.js` 的相对位置。浏览器对直接打开文件的存储支持可能不同，需要稳定保存学习记录时建议使用下述本地 HTTP 服务。

也可以在本目录运行：

```sh
npm start
```

访问 **http://127.0.0.1:4173**。用 `Ctrl+C` 关闭服务。需要 Node.js 18 或更高版本；预览服务仅用 Node 内置模块，首次预览也不需要 `npm install`。端口占用时可运行 `PORT=4174 npm start`。

macOS 还可以双击 `启动预览.command`，然后打开终端显示的网址。

## Task 2 收藏与学习足迹

- 卡片与详情页均支持收藏／取消收藏，导航栏提供收藏列表。
- 阅读页可标记“正在学习”“已学习”，也可改回“还没学”；首页和阅读页显示已学习 x/75。

- 时间为操作发生时刻，不是学习时长；显示使用浏览器本地时区。

运行 `npm run test:task2` 验收新功能（需先启动预览服务）。详细记录见 [Task 2 日志](../CHANGELOG.md)。

## Task 3 互动检测与错题本

- “诗词小挑战”可练选择上一句、选择下一句、填空字词；每轮最多 5 题，支持全库或单首诗词。
- 每个题目首次答对得 1 颗星星，重复答对仍有鼓励，不重复加星。提交后显示原句、答案及释义。
- 答错的诗自动进入错题本，保留错误次数、最近错答、时间；再次答对同一道题后标为已订正。可按待订正／已订正／全部筛选。
- 错题、星星刷新后保留；本轮位置刷新后重置。练习不改变手动学习状态。
- 填空只需输入缺失字词，忽略空格和标点；空答案不计错。
- 使用 `poetry-practice-v1` 独立保存本地记录。清除浏览器网站数据会清除记录，不跨设备同步。

运行 `npm run test:task3` 验收（先启动预览服务）；详情见 [Task 3 日志](../CHANGELOG.md)。

## 内容依据与口径

篇目、作者与排序已对照教育部发布的《义务教育语文课程标准（2022 年版）》附录 1“1～6 年级（75 篇）”：印刷页码 **58～61**，PDF 第 **65～68** 页。

官方原文：https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582344386456.pdf

课标只列篇名、首句和作者，不提供全文与译注。本项目正文采用常见教学文本，白话释义与字词解释为本项目面向儿童编写，不能把它们视为教育部提供的译注。同名诗使用作者／首句／组诗编号区分。例如两首《凉州词》分别属于王之涣、王翰，两首《绝句》按首句区分。

《古朗月行》提供 16 句全文，《赋得古原草送别》提供 8 句全文，《长歌行》提供 10 句全文。组诗采用课标所列首句对应的一首，不展示整组诗。

拼音使用现代普通话，采用本调标注：“一”“不”不标口语变调，部分常见词保留词典轻声，不为押韵改读旧音。古诗多音字在构建脚本中有明确的语境覆盖，如“见牛羊 xiàn”“单于 chán yú”“鹿柴 lù zhài”“飞将 jiàng”“鳜鱼 guì”“临行密密缝 féng”。“斜”用 xié，“鬓毛衰”用 shuāi，“返景”用 jǐng。不同教材或教师指定其他读法时，可在覆盖表统一调整。

## 编辑与验证

修改 `data/poems.txt` 后运行：

```sh
npm ci
npm run build:data
npm test
```

每条数据按 `题名|作者|朝代|原文|逐句译文|词语解释` 组织；原文和译文用 `/` 分句，数量必须相同；词语解释用 `；` 分项、英文 `:` 分隔词与解释。不要直接编辑生成的 `data/poems.js`。构建脚本会拒绝非 75 篇、句数不匹配或拼音数量不匹配的数据。

浏览器验收需先启动 `npm start`，然后在另一个终端运行：

```sh
npm run test:browser
```

默认使用本机 Google Chrome。若使用 Playwright 自带 Chromium，先执行 `npx playwright install chromium`，再执行 `PW_CHANNEL=bundled npm run test:browser`。可用 `TEST_URL` 指定其他预览地址。

浏览器验收覆盖全部 75 篇、7 页浏览、标题／作者／诗句搜索、同名诗、空结果、输入转义、逐句解释、拼音与释义开关、设置持久化、键盘切换、指南弹窗、无效链接回退、直接打开 HTML，以及全部 75 篇在 **1440 / 768 / 390 / 320 px** 宽度下的无横向溢出检查。测试会更新 `previews/` 中的截图。

## 后续扩展

每篇诗词已有独立 `id`、`dynasty` 和预留的 `illustration` 字段。可在现有搜索结果上追加朝代筛选，基于已有收藏与学习记录增加后续能力，在详情左侧增加意境插图。界面逻辑与诗词数据独立，后续也可将同样的数据结构迁移到 Flask／SQLite。

当前 ID 按固定课标顺序生成。后续不要重新排序现有记录或变更已有 ID，以免影响详情链接及未来的收藏记录。
