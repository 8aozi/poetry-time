# 诗词拾光 · 公开网页

儿童古诗词启蒙平台的静态发布版本，包含小学课标 75 篇诗词。

- 搜索、浏览、逐句释义、字上拼音。
- 收藏、学习状态与时间、x/75 学习进度。
- 上下句选择、字词填空、星星奖励、错题本与订正。

本仓库用于 GitHub Pages 发布，入口为根目录 `index.html`。使用 main 分支根目录发布，无需安装依赖或运行后端。推送网页更新后，GitHub Pages 自动部署。

完整开发代码、测试、Wiki 和阶段日志位于 [Gitee 项目仓库](https://gitee.com/lgy3417203301/SEteam26fall)。此发布版本对应 Gitee 提交 `e4bb9dc`（Task 3）。

所有学习记录仅保存在当前浏览器的当前网站地址，不跨设备同步。首次使用公开地址时不会自动继承 localhost 下的本地记录。数据损坏或存储不可用时，网页会提示。
