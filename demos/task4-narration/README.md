# Task 4 · 独立朗读 Demo（已决定不集成）

**人工 Review 结论：效果不理想。** 项目发起人试听后反馈“还是太人机了，不够真实和标准”，因此放弃本次系统语音方案，保留可复现的本地 Demo，不集成到正式项目，也不扩展到 75 篇。

## 本地启动

首次生成需要 **macOS、Python 3 和系统“婷婷”（Tingting）普通话语音**。无需 npm、第三方 Python 包、账号或 API 密钥。

在仓库根目录运行：

```sh
cd demos/task4-narration
python3 run.py
```

打开 **http://127.0.0.1:4175/**。该地址仅在本机启动服务后有效；按 Ctrl+C 停止。首次运行会自动生成五个 WAV 文件，之后复用已有文件。

端口被占用时可用 `python3 run.py --port 4176`，访问 `http://127.0.0.1:4176/`。若缺少声音，可在 macOS 系统语音设置中安装中文“婷婷”；不同 macOS 版本的设置入口可能不同。

重新生成：`python3 run.py --regenerate`。只生成、不启动网页：`python3 run.py --generate-only`。生成后也可直接打开 `index.html` 试听。Windows / Linux 不包含 macOS 的 `say`，无法原样生成此音色；若已有合法取得的本地同名 WAV，则可用同一启动脚本播放。

## Demo 内容

- 只保留《静夜思》，全诗与四句分别播放。
- 原生播放器支持暂停、进度和音量；提供停止、原速与 0.85 倍慢速。
- 慢速使用 `preservesPitch` 尽量保持音高；逐句播放时突出当前句。
- 不自动播放、不采集麦克风、不修改学习数据；与正式应用没有代码依赖。

## 音频来源与复现范围

使用系统内置合成声音，命令参数为 `say -v Tingting -r 155 --data-format=LEI16@22050`。每句独立合成，全诗依次拼接并增加 350 ms 句间停顿。系统版本或语音包变化可能影响音色。

仓库包含 HTML、生成与启动脚本和说明；生成的 WAV 通过本目录 `.gitignore` 排除，保留在本地。这样可以复现试听流程，也不将尚未核实再分发许可的系统语音录音公开上传。此次没有搬运第三方朗读录音、音乐或克隆音色。

## 决策依据

播放器可以正常工作，不代表朗读已达到教学质量。本次普通话合成语音的机械感、自然度和标准示范效果未通过人工试听；这不是专业普通话评分，也没有完成 75 篇多音字与停顿审校。

正式应用保持 Task 1–3。后续如重启朗读功能，应另选明确允许项目用途及音频发布的服务或授权录音，先由人工审听少量样本，再决定是否批量制作。
